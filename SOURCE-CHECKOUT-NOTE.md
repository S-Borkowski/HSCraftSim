# Source checkout requires local data

Game-derived data, artwork, fonts and captured research outputs have been
separated from public source snapshots. This applies to the maintained branch
and to source archives of the historical release tags.

Source archives require compatible local inputs whose use you are authorized to
make. Do not assume that an old source tag includes the previous data bundle.
The current branch documents setup in
[LOCAL-DATA.md](https://github.com/falorfrozen-cmd/HSCraftSim/blob/main/LOCAL-DATA.md).

Previously uploaded Windows EXE/ZIP assets are preserved separately. Their
embedded-content permissions remain a distinct question; source cleanup does
not certify them as cleared for redistribution. See
[DISTRIBUTION.md](https://github.com/falorfrozen-cmd/HSCraftSim/blob/main/DISTRIBUTION.md).
