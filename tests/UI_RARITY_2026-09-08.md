# Buttons and rarity filters

The shared palette in `ui/rarity.js` follows the final `.r-*` CSS declarations
in `HSItemEditor/hs_item_editor_gui.py` (4002–4003, 4149). Later declarations
override earlier ones: Heroic is `#50ddba`, Angelic `#ffe18d`, Satanic `#ff6268`,
Unholy `#c28cff`, and Runeword `#9daeff`. The editor's Superior blue is also
used for this catalog's Magic label. Item names use the palette in the catalog,
starting setup, tooltips, inspector and saved history views.

Primary buttons now use dark burgundy backgrounds with light text, including
hover and disabled states. The old pale gold fill is overridden across views.
Actual Add to Cube style: text `rgb(255,240,223)`, background gradient from
`rgb(57,36,44)` to `rgb(36,23,30)`, opacity 1. Added Great Helm successfully.

Rarity filters show matching counts, preserve the search when switching rarity,
and offer Reset filters. Only rarities represented in the selectable catalog
are shown. Compatibility candidates are cached while switching rarity; opening
the catalog or removing recipe scope invalidates that cache.
